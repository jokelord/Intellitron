Section 2: 统一事件时间线与状态机

目标：让 coordinator_1、coordinator_2、basic_agent、future agents 都落到同一套事件协议里，再由不同投影器决定给谁看什么。

Canonical Timeline Event Types

Turn Events

turn_started, user_message, turn_completed, turn_aborted

Routing Events

routing_started, routing_delta, routing_decision, routing_timeout_fallback

Visible Message Events

message_started, message_delta, message_completed

Agent Action Events

agent_switched, tool_call_started, tool_call_completed, observation_added

Main State Machine
Turn Lifecycle
User Turn
Routing Active
coordinator_1
Decision Ready
Coordinator_2 Visible Stream
Basic Agent Execution
Future Agent Execution
Done
Projection Rules

可见消息层

  • routing_delta → 任务调度卡片滚动文本
  • routing_timeout_fallback → 卡片显示“超时，已转 basic_agent”
  • message_delta(source=coordinator_2) → 普通聊天气泡流式显示
  • tool_call_* / observation_added → agent steps UI

行为层

  • routing 原文可显示，但写回上下文时要结构化
  • coordinator_2 的可见推理可保留，但上下文沉淀时要有边界
  • 工具历史按 action/observation 成对保存
