# Native helper dependency notices

The shipped `computer-use-helper` executable is built from `backend/computer_use/native/`; see its `CMakeLists.txt` and `bin/README.md`. The inspected Linux helper dynamically links GLib/GIO/GObject, JSON-GLib, PipeWire, libei, X11, Xtst, Xrandr, libc and libm. These shared libraries are obtained separately from the operating system and are not bundled by this source release. Optional CMake dependency gates can produce different linkage on another build.

The table records packages installed on the audit host on 2026-10-26. Versions are evidence for this build environment, not universal build requirements. The original distribution copyright notices are preserved byte for byte in [packages/](packages/), with hashes and origins in [SHA256SUMS](SHA256SUMS) and [PROVENANCE.tsv](PROVENANCE.tsv). Distribution copyright files describe whole upstream source packages, including files and tools that the helper may not use; their presence does not mean every listed license applies to the helper executable.
