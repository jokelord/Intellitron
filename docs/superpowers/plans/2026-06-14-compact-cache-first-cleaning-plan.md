# Compact Cache-First Cleaning Implementation Plan

> **2026-06-14 status/correction:** This plan captured the intermediate lesson "do not trim cache-first before the first attempt." Current code adds the missing speed guard: if the untrimmed cache-first source exceeds `compact.source_token_budget`, skip cache-first and run budgeted `reliable_position1` directly, with `cache_first_skipped_reason=source_exceeds_budget`. Do not execute older steps that require always sending the full untrimmed cache-first prompt.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove or delay compact pre-processing that lowers SGLang prefix-cache reuse while preserving high-value agent memory cleanup, especially tool text feedback as `user` messages.

**Architecture:** Keep two compact sources with different purposes: cache-first uses the canonical normal-prompt source unchanged plus a tail compact instruction, while reliable fallback may reshape and trim for correctness/latency. Do not make `source_token_budget` part of the first cache-first attempt; apply it only to reliable fallback and explicit budget fallback behavior. Preserve agent history semantics generated by `SmartToolCallingAgent.write_memory_to_messages()` because those same cleaned turns are also what normal agent calls consume.

**Tech Stack:** Python 3.12, FastAPI, smolagents, SGLang OpenAI-compatible chat API, pytest, existing compact modules under `backend/compact/` and agent modules under `backend/agent/`.

## Cache-Impact Classification

These are the cleaning actions found during review and how to treat them.

| Cleaning / transformation | Current location | Prefix-cache impact | Plan decision |
|---|---|---|---|
| `source_token_budget` trimming before cache-first | `backend/compact/orchestrator.py::_build_prompt_plans`, lines 136-140 | High negative: removes older messages before the first cache-first prompt, so compact no longer matches the prior normal prompt prefix. | Remove from cache-first attempt. Keep trimming for reliable fallback only. |
| Reliable compact system override | `AgentRunner._build_compact_body_messages()` and `build_reliable_source_with_compact_system()` | High negative for cache, but intentional correctness fallback. | Keep only for reliable fallback. Do not apply to cache-first. |
| Position-1 reliable compact instruction | `backend/compact/prompt_builder.py::build_compact_messages_v2()` | Breaks byte-equal prefix after system, but improves summary compliance. | Keep for reliable fallback. Cache-first already uses tail instruction. |
| Chat metadata filter replacing pre-compact history with summary envelope | `backend/compact/chat_message_filter.py` and `backend/api/chat.py` | Changes normal post-compact prompt by design. Not part of pre-compact cache-first source. | Keep. Ensure no metadata remains graceful no-op except stable compact-control clause. |
| Stable compact-control system clause | `backend/compact/prompt_control.py` and chat/agent prompt setup | Adds a stable prefix to normal prompts, enabling tail-trigger cache-first. | Keep. Do not make it turn-dependent. |
| Agent historical tool trace textification | `SmartToolCallingAgent.write_memory_to_messages()` | Neutral or positive for cache when shared by normal and compact; high semantic value. | Keep. This includes `assistant: Calling tools...` and `user: Observation:\n...`. |
| Tool artifact extraction for `write_file` / `edit_file` | `SmartToolCallingAgent.write_memory_to_messages()` | Neutral for cache when shared by normal and compact; high semantic value. | Keep. Prevents history from becoming success receipts only. |
| File success receipt filtering to `已完成。` boundary | `SmartToolCallingAgent.write_memory_to_messages()` | Neutral for cache when shared by normal and compact; high semantic value. | Keep. Prevents model from learning to only report success. |
| Historical task image stripping and action image stripping | `SmartToolCallingAgent.write_memory_to_messages()` | Changes prompt shape, but is used by normal agent prompts too; prevents visual-token blowup and cross-turn image leakage. | Keep. Do not reintroduce old images for cache. |
| Runtime context injection | `LocalLLMModel._inject_runtime_context()` and `AgentRunner._build_cache_first_compact_body_messages()` | Can break cache if compact and normal inject it differently. | Ensure cache-first uses the same pinned `session.runtime_context` placement as normal calls. |

Hard preservation requirement from `踩坑记录2.md` lines 117-135, 239-269, 391-404:

```text
assistant: Calling tools: [...]
user: Observation:\n...
```

This must remain a `user` role observation after tool text feedback. Do not rewrite historical tool turns into natural-language assistant summaries.
